## One library. A complete management path.

<div class="features"><article><h3>Scan to enroll</h3><p>Generate a private QR from verified APK bytes. Use a LAN IP or domain, with the transport you configure.</p></article><article><h3>Deploy signed apps</h3><p>Register, assign and observe APK installation. Resume downloads and recover durable installer sessions.</p></article><article><h3>Policies and kiosk</h3><p>Required apps, Lock Task, runtime permissions and selected restrictions, with separate per-rule observations.</p></article><article><h3>Embed, don't rebuild</h3><p>Durable SQLite/filesystem defaults, protected Android state, public APIs and optional host adapters.</p></article></div>

## Try the reference experience

The server console creates enrollment QR codes, switches their network destination, manages applications and policies, and displays device/operation results. The Android app shows desired versus observed apps, installation progress and policy compliance.
