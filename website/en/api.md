# API reference

API documentation is generated from current source signatures and purpose/usage comments:

- [Go facade, persistence contracts, adapters and provisioning](../api/go.html)
- [Android host API and platform components, generated by Dokka](../api/android/index.html)

The language-neutral signatures and source comments are shared technical references. Start with the [integration guide](install.html) for the host lifecycle and an executable usage path. Implementation and generated protocol classes are not general plugin contracts.

## Common Go actions

| Goal | API |
| --- | --- |
| Construct/close | `New`, `Close`, `Handler`, `BootstrapHandler`, `Version` |
| Provision | `CreateEnrollment`, `QR`, `QRWithOrigins` |
| Registry | `ListDevices`, `RevokeDevice` |
| Apps/updates | `RegisterApplication`, `ListApplications`, `AssignApplication`, `ListOperations`, `RemoveApplication` |
| Policy | `SetPolicy`, `GetPolicy` |
| Extension | `ports.StateStore`, `ArtifactStore`, `portstest`, `Options.Events`, `Clock` |

## Common Android actions

| Goal | API |
| --- | --- |
| Request reconciliation | `Kylok.retry(context)` |
| Read current local state | `Kylok.snapshot(context) { AgentStatus -> … }` |
| Observe updates | `Kylok.observe(StatusListener { … })`; close the registration |
| OS installation confirmation | `Kylok.confirmPendingInstall(context)` from a user action |
| Diagnostics | `Kylok.status`, `sdkVersion`, `protocolVersion` |

`AgentStatus` separates application desired/observed state, policy results and durable local installation progress. Credentials, QR contents and private keys are excluded.
